# Provisional recommendation rules

- `CATALOG_POSITIONING_V1`: offers dated manufacturer-positioning categories as comparison candidates; it does not establish personal performance or fit.
- `USER_PRIORITY_V1`: uses the stated preference as a deterministic ordering hint. No score, probability, performance prediction, or validated inference is produced.
- Known handedness and verified purchasable combinations must be eligibility constraints in a production catalog. This demo's catalog does not include verified configurations, so it presents reference comparisons only and never says they are purchasable or in stock.
- Shaft, length, lie, and grip evidence remain unknown unless supported by appropriate evidence. Height, wrist-to-floor, handicap, or one speed value cannot yield an exact recommendation.
- Next test: compare candidates in similar conditions and with the same ball, recording carry (not total), strike consistency, start line, peak height, and stopping. Ask a qualified fitter to confirm configuration availability.

These heuristics are unvalidated and must not be described as professional fitting accuracy.
